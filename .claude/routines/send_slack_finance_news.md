# 루틴 이름: 증시 뉴스 요약 및 슬랙 전송

이 루틴은 사용자가 지정한 주식 종목 또는 증시 키워드 관련 최신 뉴스를 검색하고 빠르게 요약하여 슬랙 채널로 전송합니다.

## 매개변수 (Arguments)
- `keyword`: 검색할 주식 종목명 또는 증시 키워드 (기본값: "국내 증시")

## 실행 단계

1. **최신 뉴스 고속 검색**:
   - 제공된 `keyword`와 관련된 최신 뉴스 목록을 검색하세요.
   - 각 기사 본문을 전부 다 읽으려 하지 말고, 검색 결과에 나오는 **제목과 스니펫(요약 정보) 위주로 상위 3~4개 기사만 빠르게 파악**하세요. (속도가 중요합니다.)

2. **콤팩트 브리핑 작성**:
   - 파악한 내용을 바탕으로 오늘 시장의 핵심 이슈를 3줄 요약 형태로 아주 콤팩트하게 작성하세요.
   - 결과물은 슬랙 마크다운 형식에 맞게 이모지를 섞어 보기 좋게 포맷팅하세요.

3. **슬랙 전송**:
   - 환경변수 `SLACK_WEBHOOK_URL`을 활용하여 `curl` 명령어로 슬랙 웹훅에 즉시 전송하세요.
   - 전송 후 루틴을 바로 종료하세요.
