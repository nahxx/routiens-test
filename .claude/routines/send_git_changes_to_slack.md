# 루틴 이름: 저장소 변경 내용 슬랙 전송

이 루틴은 현재 Git 저장소의 변경 사항(Staged 또는 Unstaged 변경점, 혹은 최근 커밋)을 요약하여 슬랙 채널로 전송합니다.

## 시스템 환경 요구사항
- 슬랙 웹훅 URL 환경변수 (`SLACK_WEBHOOK_URL`)가 설정되어 있어야 합니다.

## 실행 단계

1. **변경 사항 확인**: 
   - `git status` 및 `git diff`를 실행하여 현재 작업 디렉토리의 변경 내용을 파악하세요.
   - 만약 변경 사항이 없다면, 가장 최근 커밋 1개의 내용(`git log -1 -p`)을 파악하세요.

2. **변경 요약문 작성**:
   - 파악한 코드 변경점을 바탕으로 개발자가 읽기 좋은 형태의 요약문을 작성하세요.
   - 요약문에는 어떤 파일이 수정되었는지, 주요 변경 목적이 무엇인지가 포함되어야 합니다.
   - 결과물은 슬랙 마크다운 형식(Slack mrkdwn)에 맞게 깔끔하게 포맷팅하세요.

3. **슬랙 전송**:
   - 환경변수에서 `SLACK_WEBHOOK_URL`을 가져옵니다.
   - 만약 환경변수가 비어있다면 사용자에게 입력을 요청하세요.
   - 작성된 요약문을 JSON 페이로드(`{"text": "요약문 내용"}`)로 만들어 `curl` 명령어를 통해 슬랙 웹훅으로 전송하세요.
   - 전송에 성공하면 사용자에게 성공 메시지를 출력하세요.
